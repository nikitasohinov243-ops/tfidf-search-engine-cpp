# TF-IDF Search Engine

Консольный мини-поисковик по набору текстовых файлов на C++17. Считает TF, IDF и TF-IDF, показывает значимые слова документа и ранжирует документы по поисковому запросу.

## Возможности
- Загрузка списка документов из `documents.txt`.
- Нормализация слов: удаление знаков препинания, приведение к нижнему регистру.
- Четыре команды:
  - `WORD <слово>` — IDF слова и список документов, где оно встречается;
  - `WORD_IN_DOC <слово> <документ>` — количество, TF и TF-IDF слова в документе;
  - `DOC <документ>` — общее число слов, число уникальных слов и топ-5 по TF-IDF;
  - `QUERY <слова>` — ранжированный список документов по сумме TF-IDF слов запроса.
- При равных оценках документы и слова сортируются по алфавиту.

## Формулы
- `TF = число вхождений слова / число слов в документе`
- `IDF = ln(N / df)`, где `N` — число документов, `df` — число документов со словом
- `TF-IDF = TF · IDF`

Слово, которое есть во всех документах, получает IDF = 0.

## Сборка и запуск
```bash
g++ -std=c++17 -O2 main.cpp -o tfidf_lab
cd examples
../tfidf_lab
```
Команды вводятся с клавиатуры или подаются из файла: `../tfidf_lab < commands.txt`.

## Пример
Файлы: `doc1.txt` — «Machine learning is great. Learning data is important.», `doc2.txt` — «Algorithm and model structure. This model is a machine.»

```
QUERY learning model
```
```
Query: learning model
Results:
1. doc1.txt (0.1733)
2. doc2.txt (0.1540)
```

```
DOC doc2.txt
```
```
Document: doc2.txt
Total words: 9
Unique words: 8
Top words:
1. model (0.1540)
2. a (0.0770)
3. algorithm (0.0770)
4. and (0.0770)
5. structure (0.0770)
```

## Структура
- `main.cpp` — чтение документов, цикл обработки команд
- `document.h` — структура `Document` и нормализация слов
- `engine.h` — расчёт TF/IDF и обработчики команд

## Стек
C++17 · STL (`unordered_map`, `set`, `vector`, алгоритмы сортировки)

## Ограничения
- Корректно обрабатывается текст в ASCII; кириллица и другая многобайтовая кодировка не нормализуются.
- Знаки препинания удаляются и внутри слова (`don't` → `dont`).
